# Çanta Mağazası

A bag store in plain HTML, CSS and JavaScript (no framework, no build step).

**Try it:** https://asmaa21102.github.io/live/canta-magazasi/index.html

## Features

- Instant search, categories, a price filter and sorting
- Quick view and favourites
- Cart saved in the browser and a demo checkout with form validation (no real payments)
- Arabic, English and Turkish, dark mode, mobile-friendly

## Run

Open `index.html` in a browser.
